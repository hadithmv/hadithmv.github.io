This image shows the user interface of **Al-Maktaba Al-Shamela** (المكتبة الشاملة), a widely used Arabic digital library software designed for searching, reading, and researching classical Islamic texts, Arabic poetry, tafsir, hadith, and historical literature.

Here is a detailed breakdown of the components in the screenshot:

---

### **1. Navigation Toolbar (Far Right)**
A vertical menu bar with navigation tabs for filtering or browsing the library:
* **الكتب** *(Books)* – *Currently active tab*
* **التصنيف** *(Categories / Classifications)*
* **المؤلفون** *(Authors)*
* **فترة** *(Historical Periods)*
* **المفضلة** *(Favorites)*
* **مؤخرا** *(Recently opened)*
* **تنزيلات** *(Downloads)*
* **المجالات** *(Fields / Domains)*
* **السجلات** *(Search / Reading Logs)*

---

### **2. Main Content Area: Book Selection List (Center/Right)**
* **Filter Bar (Top):** Allows searching by typing a book title, author's name, or both (`يمكن البحث بجزء من اسم الكتاب أو المؤلف أو كليهما`).
* **Table Columns:**
  * **الكتاب** *(Book Title)*: Displays titles such as various *Diwans* (poetry collections of pre-Islamic and early Islamic poets like Amr ibn Qami'ah, Imru' al-Qais, Al-Afwah al-Awdi, Tarafa ibn al-Abd), as well as *Tafsir* (exegesis) works (e.g., Tafsir Mujahid, Tafsir Ibn Sirin).
  * **المؤلف** *(Author)*: Displays author names alongside their year of death (e.g., `ت ٥٤٠ م` for death in 540 AD / CE).
* **Selection Checkboxes:** Located to the right of each book entry to select specific titles for search.
* **Bottom Bar:** Options to select all (`اختيار الكتب المحددة`), deselect all (`إلغاء الكتب المحددة`), or ignore filters (`تجاهل`).

---

### **3. Search Options & Query Panel (Left)**
This pane configures detailed search parameters and query terms:

* **Search Scope (`البحث في`):**
  * **المتن** *(Main Text)* – *Checked*
  * **الحواشي** *(Footnotes)* – *Checked*
  * **التعليقات** *(Comments)*
  * **العناوين** *(Headings / Titles)*

* **Text Matching Options:**
  * **بحث صرفي** *(Morphological / Root-based search)*
  * **بحث باللواصق** *(Search with affixes)*
  * **مراعاة الهمزات** *(Match Hamzas)*
  * **مراعاة التشكيل** *(Match diacritics / vocalization)*
  * **مراعاة الأرقام** *(Match numbers)*

* **Logic Operators & Conditions:**
  * Logical operations: **و** *(AND)*, **أو** *(OR)*, **ليس** *(NOT)*.
  * Options for term conditions: **يلزم وجود كل العبارات** *(All terms required)*, **مرتبة** *(In order)*, **متقاربة** *(Proximity search)*.
  * Numbered text input fields (1 through 5) to type search keywords.

* **Bottom Status Bar:**
  * `مجال البحث الحالي: جميع الكتب` *(Current search scope: All books)*.

This cropped screenshot shows a dropdown context menu opened by clicking the small folder/arrow button located at the top-left of the query fields section.

Here is a breakdown of the menu options and their functions:

---

### **1. Top Option**
* **إضافة مجموعة جديدة** *(Add a new group)*: Allows adding an additional search group block to build complex, multi-stage search logic.

---

### **2. Logical Operator Guide & Selection**
The middle section explains and allows selecting the boolean condition for search terms:
* **و : يلزم وجود كل العبارات** *(AND : All phrases must be present)*
* **أو : يلزم وجود عبارة أو أكثر** *(OR : At least one phrase must be present)*
* **ليس : يلزم غياب كل العبارات** *(NOT : All phrases must be absent)*

---

### **3. Bottom Option**
* **استعادة المجموعات الافتراضية** *(Restore default groups)*: Resets the search group structure and logical rules back to their default configuration.
