the issue:

there's a path mismatch in the Tauri build process. The build script is looking for a permissions file at an incorrect path:

Expected path: D:\hadithmv\hadithmv.github.io\app\windowsApp-tauri\Hadithmv\src-tauri\...

Actual path being used: D:\hadithmv\hadithmv.github.io\windowsApp-tauri\Hadithmv\... (missing the /app/ directory)

This is typically caused by a stale build cache. Try these steps:

Clean the Rust/Cargo build artifacts:
cd src-tauri
cargo clean
cd ..

Delete node_modules and package lock:
rm -r node_modules -Force
rm package-lock.json
npm install

Reinstall Tauri CLI:
npm install @tauri-apps/cli@latest @tauri-apps/api@latest

Try running again:
npm run tauri dev
